# Оборудование для собственного запуска GLM‑5.3 и DeepSeek V4 Pro 0813

Оцениваем покупку оборудования в России для двух полных моделей, проверенных через OpenRouter. Ограничение 200–400 тысяч рублей снято. Цены прочитаны 28 ноября 2026 года; это предложения продавцов, не коммерческое предложение и не найденный минимум рынка. Сборку и скорость на этом оборудовании мы не проверяли.

## Сколько памяти нужно

Берём конкретные GGUF от Unsloth, чтобы не выводить память только из числа параметров. Размеры ниже — сумма `size` всех частей выбранной папки через API Hugging Face; полный список сохранён в [hardware-evidence.json](hardware-evidence.json).

| Модель и файл | Вес файлов, десятичные ГБ | Оценка памяти для короткого разговора |
|---|---:|---|
| [GLM‑5.3, UD-Q4_K_XL](https://huggingface.co/unsloth/GLM-5.3-GGUF/tree/main/UD-Q4_K_XL) | 467.29 | RAM 768 ГБ с запасом; при запуске целиком на GPU ориентир 576–768 ГБ VRAM |
| [DeepSeek V4 Pro 0813, UD-Q4_K_XL](https://huggingface.co/unsloth/DeepSeek-V4-Pro-0813-GGUF/tree/main/UD-Q4_K_XL) | 849.68 | RAM от 1 ТБ, предпочтительно 1.5 ТБ; GPU ориентир 1.1 ТБ VRAM |

Это оценка для одного пользователя и контекста порядка 8 тысяч токенов, а не расчёт максимального контекста 1 млн. Дополнительно нужны память под вычисления, историю, runtime и ОС. RAM и VRAM не складываются в одну одинаково быструю память; перенос вычислений на CPU меняет скорость. Активные параметры MoE уменьшают объём вычислений за шаг, но хранить приходится веса всех экспертов.

Выбранный GLM-файл UD-IQ4_XS меньше — около 365.31 ГБ, но это другая квантизация. У DeepSeek отдельная особенность: опубликованный checkpoint уже смешивает FP4 и FP8, поэтому простая формула «всё FP8 = один байт на параметр» не описывает его фактический размер. [Документация vLLM](https://recipes.vllm.ai/deepseek-ai/DeepSeek-V4-Pro).

## Конкретные ориентиры покупки

| Модель | Запуск с весами в RAM | Веса целиком на GPU |
|---|---|---|
| GLM‑5.3, указанный GGUF | [Dell R7525, 2× EPYC 7713, RAM 1024 ГБ, 4× SSD 3.84 ТБ](https://servakmaster.ru/catalog/servery/dell-r7525-12lff-2): **2 259 200 ₽**, б/у, под заказ | [ASUS ESC8000A‑E13, 8× RTX PRO 6000 по 96 ГБ, RAM 768 ГБ](https://start-server.ru/catalog/ai-servery/servery-s-nvidia-rtx-pro-6000-rtx-a5000/ai-server-asus-esc8000a-e13-sku1-8-rtx-pro-6000-bse-96gb-2-epyc-9575f-ram-768gb): **от 13 189 600 ₽**, цена зависит от поставки |
| DeepSeek V4 Pro 0813, указанный GGUF | Тот же Dell с 1 ТБ RAM: **2 259 200 ₽** как кандидат для проверки загрузки; запас меньше, чем у GLM | [Gooxi, 8× H200 по 141 ГБ, 2× Xeon Gold 6454S](https://3dimport.ru/shop/servers/servers-for-ai/server-ii-xeon-8x-nvidia-h200-141gb-gooxi/): **50 895 900 ₽** за опубликованную комплектацию; установлено лишь 64 ГБ RAM, её расширение оплачивается отдельно |

Первый столбец даёт возможность экспериментировать с CPU-инференсом. Он не обещает удобного голосового разговора. Нельзя назвать эти 2.26 млн ценой гарантированно быстрой станции: ни токены в секунду, ни время до первого слова на таком сервере нами не измерены. Это также не минимально возможная цена загрузки: б/у комплектующие и более сильная квантизация могут дать другой бюджет, но их качество и совместимость здесь не проверялись.

Второй столбец подбирается по вместимости. Для GLM 768 ГБ VRAM оставляют существенный запас относительно файла 467 ГБ. Для DeepSeek 8×96 = 768 ГБ недостаточно даже для выбранных весов 850 ГБ; 8×141 = 1128 ГБ дают запас. Возможность запуска конкретного GGUF на конкретном backend нужно проверить перед покупкой: одна сумма VRAM не доказывает поддержку формата, распределения слоёв и приемлемую скорость межкарточного обмена.

Для DeepSeek официальный [рецепт vLLM](https://recipes.vllm.ai/deepseek-ai/DeepSeek-V4-Pro) описывает 8× H200 с исходным смешанным checkpoint — это дополнительное подтверждение реалистичности класса оборудования, но не измерение выбранного GGUF и не сертификат совместимости Gooxi. Для GLM официальный [рецепт](https://recipes.vllm.ai/zai-org/GLM-5.3) по умолчанию использует 8× B300 и FP8. Это производительный пример, а не минимальные требования; [Unsloth](https://unsloth.ai/docs/models/GLM-5.3) описывает запуск GGUF через llama.cpp.

## Что включено в цену

В таблице — только сервер в комплектации страницы. Не включены настройка ПО, расширение RAM, стойка, UPS, размещение, дополнительное охлаждение и электричество. Мощность блоков питания не равна измеренному потреблению.

Для иллюстрации текущих расходов: при среднем потреблении 1 кВт круглосуточно и условном тарифе 8 ₽/кВт·ч получится 1 × 24 × 30 × 8 = **5760 ₽ за 30 дней**. При 5 кВт — **28 800 ₽**. Это сценарный расчёт с заданными предположениями, не замер выбранных серверов и не проверенный тариф для адреса.

У продавцов встречаются сильные расхождения. Например, другая страница [ASUS с 8× RTX PRO 6000](https://serverflow.ru/catalog/ai-servers/asus-esc8000-e12p-8-rtx-pro-6000-bse-2-xeon-6962p/) при открытии показывает 48 196 800 ₽, хотя поисковый фрагмент давал меньшую сумму. Поэтому выше стоят цены из открытых карточек, а не сниппетов. Перед закупкой нужны точная комплектация и актуальное КП.

Практический вывод для текущего исследования: сначала оцениваем ответы через API за доли цента. Покупку выбираем после проверки качества и арендного запуска точной квантизации с замером скорости. [Результаты коротких разговоров](comparison-ru.md).
