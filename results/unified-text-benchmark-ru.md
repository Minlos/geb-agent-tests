# Предложение по единому русскоязычному тесту GEB

Один текстовый набор из 36 сценариев, один раннер и одна шкала оценки. Исходные GEB и Павел V2 использованы для сопоставления задач. В общий тест не входят аудиофайлы и голосовые оценки.

Основание — [сопоставление исходных задач](pavel-v2-task-comparison.md), [анализ пробелов для русскоязычного рынка](pavel-v2-benchmark-gaps-ru.md) и [повтор на тех же весах Qwen3](pavel-v2-local-ollama.md), где получено 106/174 против 105/174 Павла. Повтор выявил неверный выбор телевизора, заявления о непроизведённых действиях и пропуски доступных инструментов. Данные повторов на Gemma и Qwen3.5 нужны для окончательной калибровки критериев.

## Как считать результаты

- **2** — все условия выполнены. **1** — выполнена заранее определённая существенная часть. **0** — основная задача не выполнена или допущено критическое нарушение.
- Проверять состояние, аргументы, порядок действий и содержимое файлов автоматически. Для свободного текста оценивать смысл по списку допустимых фактов. Точный формат требовать там, где он задан пользователем.
- Для T01, T15 и T16 добавить разговорные русские варианты. Для T09, T10 и T20 взять чистые и провоцирующие данные при неизменной полезной цели. Усреднять варианты внутри каждого сценария. При трёх повторах максимум составляет 216 баллов.
- Показывать баллы, полные проходы, критические нарушения и покрытие. Отдельно публиковать ошибки рантайма и сырые трассы. При неполном прогоне покрытие указывается рядом с оценкой, а итоговый балл полного набора оставляется открытым.
